# OpenPPX v0.6.0 Teach Agents & Automate Work Preview

> 状态：GitHub Pre-release。它面向开发者测试，不应描述为稳定或生产就绪版本。
> 版本边界：本文只描述 `v0.6.0` tag 和对应发布资产中实际包含的能力。

`v0.6.0` 让 OpenPPX 从持久 Agent 工作台进一步成为可教学、可自动化、可治理的 Agent OS。所有对话、Skill、Automation、Subagent、App/MCP Tool 和权限检查仍通过统一 Node Contract 与 Google ADK Runtime 执行。

## 本版本重点

- **从对话沉淀 Skill：** `/make-skill [focus]` 从当前 Session 的可见内容生成可审查草稿，支持 revise、cancel 和显式 approve；敏感值会预先脱敏，发布结果保留来源与审批 provenance，并只为当前 Agent 启用。
- **持久工作与自动化：** Goal、TaskFlow、Checkpoint、Automation、Cron、Monitor 和独立 ADK Run 形成统一执行闭环，Desktop 可创建、暂停、立即运行并查看历史。
- **受治理的 Subagent：** 后台 Subagent 继承固定 Agent、Workspace、Model、Extension 和权限 revision，限制递归委派，并把进度、结果与取消状态保存在正式 Task facts 中。
- **静态权限与隔离：** Agent Workspace、Session、Model 和 Extension 彼此隔离；文件、命令、进程、网络和 Tool 权限在执行边界重新检查，权限收紧无需等待旧 Runtime 结束。
- **Apps、MCP 与 Office：** 统一的 Extension 生命周期覆盖 Skills、Plugins、Apps 和直接 MCP；首批只读 Office 连接器复用 SecretRef、Tool allowlist、Network policy 和审计边界。
- **真实工作文件：** DOCX、XLSX、CSV、文本 PDF、PPTX 和常见图片经过 Node 权威校验后成为持久 Artifact，支持 Session 归属、下载、fork、archive、restore 和 delete。
- **更清晰的 Desktop：** 配置页支持连续滚动与步骤定位；Agent 创建统一进入 Settings；连接测试、Model access、App configured 状态与 Session Archive 均提供明确、可恢复的反馈。

## 统一执行边界

```text
CLI / Desktop / Slash / Agent Tool
  → Typed Action Registry + policy + audit
  → Node-owned Config / Session / Goal / Automation / Extension services
  → Google ADK Runner + Session + ToolContext + callbacks/events
  → Task / Artifact / Trace / usage / audit facts
```

生成的 Skill 文本不能授予额外能力。Agent privilege、静态权限、App/MCP grants、高风险确认和不可变 Runtime snapshot 仍是最终执行边界。

## 已知限制

- 仅正式提供 macOS Apple Silicon Desktop 预览包；没有 Windows、Linux 或 Intel macOS 安装包。
- macOS DMG 未使用 Apple Developer ID 签名或 notarization，系统可能显示来源验证提示。
- OpenPPX Node 仍需单独安装、配置和运行；Desktop 安装包不包含 Python、模型凭据或用户数据库。
- 外部 Apps/MCP 需要用户自己的服务账户与凭据；当前 Office 连接器有意限制为只读能力。
- Client API 不应直接暴露到公网；公网 Relay、自动 TLS/发现、Mobile、完整企业 IAM 和生产级云托管不在本版本范围。
