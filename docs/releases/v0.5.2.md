# OpenPPX v0.5.2 Developer Preview

> 状态：GitHub Pre-release。它面向开发者测试，不应描述为稳定或生产就绪版本。

`v0.5.2` 将近期完成的 Node 架构升级和 Desktop 产品化改进整理为一个可安装的开发者预览。OpenPPX Node 现在统一拥有配置、模型、扩展、操作记录、自动化与 Agent 运行时状态；CLI 和 Desktop 通过同一套 Client Contract 使用这些能力。

## 本版本包含

- 建立单一 Node、Config、Action、Extension、Operations 和 Client Contract 架构，移除并行的旧运行与配置路径。
- 提供严格的 Node/Agent 配置校验、版本冲突检测、预览/应用、诊断脱敏和真实首次运行验证。
- 统一 Plugin、App、MCP 与 Skill 扩展模型，支持发现、安装、校验、启用和运行时投影。
- 扩充 CLI、斜杠命令与 Action 能力，补齐审计、用量、Cron、Heartbeat 和受治理的 Node Operations。
- 增加 Node 管理的 OpenAI Codex OAuth 状态、认证引导和可用模型目录。
- Desktop 支持创建 Agent，以及新增、编辑和选择带显示名称的 Model Profile。
- 改进首次设置与错误诊断，让配置资源损坏、认证缺失和模型首轮失败显示为可操作的问题。
- 精修三栏 Workspace：更紧凑的 Session 列表、更一致的消息版式、用户消息右对齐、可调栏宽、账户菜单和 Settings 导航。
- 保持 Desktop 与 Node 前后端分离，可在同一台机器运行，也可连接可信局域网中的另一台 Node 机器。

## 架构边界

```text
CLI        OpenPPX Desktop        Future clients
 |                |                     |
 +----------------+---------------------+
                  |
         Shared Client Contract
           HTTP + SSE + Actions
                  |
            OpenPPX Node
 Config / Models / Extensions / Operations / Audit
                  |
     Google ADK runtime + immutable snapshots
```

Node 是业务事实的唯一来源。Desktop 只保存窗口布局和连接目标等设备偏好，不直接修改 Node 的业务文件，也不持有普通 Renderer 可读取的模型凭证。

## 已知限制

- 仅验证 macOS Apple Silicon；尚无 Windows、Linux 或 Intel macOS 安装包。
- macOS DMG 未进行 Apple Developer ID 签名或 notarization，系统可能显示来源验证提示。
- OpenPPX Node 仍需单独安装、配置和运行。
- 真实两台物理机器的完整局域网验收尚未完成；局域网模式仅适用于可信网络。
- 不应将 Client API 端口直接暴露到公网；自动 TLS、SSH tunnel、Tailnet 和公网 Relay 尚未产品化。
- 当前 Desktop 只保存一个活动连接目标；多 Node 列表、自动发现和配对仍属于后续规划。
- Extension 与 Operations 已建立长期架构边界，但生态目录和部分高级管理界面仍会继续扩展。

## 发布验证

发布候选通过 Python、TypeScript Client 和 Desktop 测试，检查版本一致性、wheel 构建与安装、Electron preload、打包后的 App 启动路径、DMG 完整性和 SHA-256 清单。具体安装与构建方式见仓库根目录及 `apps/desktop/README.md`。
