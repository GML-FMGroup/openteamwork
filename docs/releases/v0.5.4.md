# OpenPPX v0.5.4 Goal & Automation Preview

> 状态：GitHub Pre-release。它面向开发者测试，不应描述为稳定或生产就绪版本。
> 版本边界：本文只描述 `v0.5.4` tag 和对应发布资产中实际包含的能力。

`v0.5.4` 将 Goal、Automation、Slash Command、Task、Trace 和 Extension diagnostics 纳入统一 Node Contract，并继续使用 Google ADK 作为唯一模型执行 Runtime。CLI、Desktop、Slash 和 Agent Tool 都通过同一 Action 边界工作，不建立第二套 AgentLoop。

## 本版本包含

- 正式的 Goal 与 TaskFlow 资源：持久 revision、Agent/Workspace/Session 绑定、步骤依赖、预算、等待、Checkpoint provenance 和完成证据。
- 正式的 User Automation 资源：schedule、manual 和受控 local-event trigger；retry、concurrency、budget、monitor、delivery、history 和六个模板。
- 每次 Automation 执行使用独立 Google ADK Session/Run；Goal Tool 通过 ADK `ToolContext` 读取与推进状态。
- typed `/goal`、`/model`、`/task`、`/automation` 和标准兼容的 `/skill <name> [instruction]`，并在 Desktop 命令面板提供搜索、参数提示、最近命令和不可用原因。
- model/tool/queue/Extension duration、TTFT、correlation ID、结构化错误、脱敏与 `runtime.inspect`。
- Extension health 历史、最近成功/失败、延迟与连续失败诊断；Skill/Plugin/App scaffold、validate、package 和官方 ADK Eval。
- Desktop Automations、Goal Progress、运行诊断和 device-local Preferences；当前界面语言明确为 English。
- Node-authoritative DOCX、XLSX、CSV、text PDF、PPTX、PNG、JPEG 和 WebP 校验、受限提取、Artifact 下载以及 Session fork/delete 生命周期。

## ADK 原生执行边界

```text
CLI / Desktop / Slash / Agent Tool
  → Action Registry
  → Node-owned domain service
  → Google ADK Runner + Session + ToolContext + callbacks/events
  → TaskRun / Artifact / Delivery / Trace facts
```

MCP/App 继续通过 ADK MCP Toolset 投影；Extension Eval 使用 ADK `EvalSet` 和 `AgentEvaluator`。参考项目只用于产品语义和交互设计，不引入 nanobot/OpenWorker 的独立执行循环。

## 已知限制

- 仅正式支持 macOS Apple Silicon；没有 Windows、Linux 或 Intel macOS 安装包。
- macOS DMG 未使用 Apple Developer ID 签名或 notarization，系统可能显示来源验证提示。
- OpenPPX Node 仍需单独安装、配置和运行。
- 真实 OAuth/API-key Extension、真实双机局域网和真实长任务故障恢复仍需外部 E4 验收。
- Client API 不应直接暴露到公网；公网 Relay、自动发现、Mobile、公共 SDK 和 OpenAI-compatible API 不在本版本范围。
- Dream、长期 Memory 自演化和完整企业 IAM 仍属于后续路线。
